# Brand assets

The white rabbit is the shared Follow the Bitcoin logo. The approved concept was
created with Imagegen and its silhouette implemented as an editable SVG. These
assets are included under the repository's MIT license.

| Asset | Use |
| --- | --- |
| `public/brand/white-rabbit.svg` | Editable white mark with a transparent background |
| `public/brand/white-rabbit.png` | 512 × 512 transparent mark, including local badge exports |
| `public/favicon.svg` | Self-contained icon on the dark project background |
| `public/favicon.ico` | 16, 32 and 48 px browser icons |
| `public/brand/icon-192.png` | 192 px icon and repository README |
| `public/apple-touch-icon.png` | 180 px home-screen icon |
| `public/brand/social-card.png` | 1200 × 630 website and repository sharing preview |

Keep the silhouette white, its proportions intact and its internal cutouts open.
Use it on a dark background with room around the ears, tail and feet. The mark
is decorative beside the existing accessible project name; it adds no slogan.

Both quest badges carry the rabbit while retaining their own quest number,
name, colours and illustration. Their PNGs are composed in the browser from
the same-origin mark; no external image service or personal data is involved.
