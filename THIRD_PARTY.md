# Third-party components

The application code and original quest text are MIT-licensed. Dependencies keep
their own licenses, included in each npm package. `package-lock.json` records
exact resolved versions and integrity hashes; it is the dependency inventory.

- React: MIT.
- Vinext and Vite: MIT.
- Base UI, shadcn/ui and Tailwind CSS: MIT.
- Lucide icons: ISC (and the MIT-licensed Feather icons noted upstream).
- Bundled Sites integration: MIT, build/development tooling. It is not a user
  account requirement of the static release.

No stock photographs, remote fonts or generated raster artwork are used. Badge
cards contain project typography and simple geometric layout, generated locally.
Educational references are linked, not copied in full. Real-case quests must
record their sources and any separately licensed assets before acceptance.
